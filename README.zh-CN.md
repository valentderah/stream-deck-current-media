# 当前媒体（Now Playing）

<img alt="image" src=".github/assets/banner.png" />

一款 Stream Deck 插件，用于显示来自各种来源的当前播放媒体信息，并提供高级播放控制功能。

## 功能

- **动态显示**：显示封面、标题和艺人信息，以及来源（Spotify、Chrome 等）。
- **大封面模式**：组合 2x2 键位网格以显示单张大封面图片。
- **播放控制**：提供播放/暂停、下一首和上一首曲目的专用操作。
- **快进/快退功能**：支持快进和快退操作，快进步长可按秒配置。
- **长按动作**：可为按键的长按分配第二个动作，例如下一首或快进。
- **Stream Deck+ 旋钮与触控条**：在触控条上显示封面、标题、艺人以及带有已播放和总时长的进度条。
- **空闲背景**：没有播放内容时，触控条显示在动作设置中选择的自定义图片；播放时由封面替代。
- **分组设置**：设置按键、旋钮、触控条和显示四个分组。
- **完全可自定义**：可配置按键触发动作，包括是否显示媒体来源、标题或艺人等信息。
- **跨平台支持**：支持 Windows 和 macOS。
- **广泛兼容性**：支持 Spotify、Chrome、Yandex Music、Apple Music 等集成 Windows (SMTC) 和 macOS 系统媒体控制的应用程序。

## 系统要求

- **Elgato Stream Deck 软件**：6.9 版或更高版本
- **操作系统**：
  - Windows 10 或更高版本
  - macOS 10.15 或更高版本

## 手动安装

1. 从 [发布](https://github.com/valentderah/stream-deck-current-media/releases) 页面下载最新版本。
2. 双击下载的 `.streamDeckPlugin` 文件进行安装。
